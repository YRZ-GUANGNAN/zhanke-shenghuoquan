# 评论互动实现回执

日期：2026-10-14

## 本轮范围

- 社区帖子详情新增一级评论下的回复线程。
- 评论与回复支持独立点赞，计数由服务端事务确认。
- 帖子点赞成功后使用服务端权威计数；初始状态读取失败时不允许误操作。
- 保留现有审核、权限、功能开关、路由、蓝色主题和接口兼容。
- 二手评论、咨询模块和后台开关未改动。

## 实现要点

- 新增迁移 `043_community_comment_interactions.sql`，建立评论层级字段和 `comment_likes` 唯一关系表；提供对应回滚脚本。
- 新增评论线程仓储、服务和 handler。回复目标由服务端根据同帖公开评论推导，客户端只提交正文和幂等请求号。
- 旧评论列表继续只返回根评论，避免旧客户端把回复误当成独立评论。
- 待审核和拒绝内容仅对作者本人可见；下架评论或帖子不可继续回复或点赞。
- 前端按评论粒度维护点赞锁、回复目标、草稿和重试状态，失败时保留输入内容。

- `node scripts/test-feature-policy-mysql.cjs --comment-interactions`：隔离 MySQL 迁移、审核可见性、回复归属、并发点赞和计数场景通过。
- `git diff --check`：通过。

## 交付边界

当前只完成隔离分支源码和验证，未执行线上数据库迁移、后端发布、小程序上传、微信审核或正式发布。生产环境要启用本轮功能，需先备份线上数据库并执行 043 迁移，再同步发布后端和小程序包；缺少任一步都会导致新评论接口不可用。

真机键盘、系统字号、不同微信基础库下的触控和视觉效果仍需在开发者工具及手机上验收。
