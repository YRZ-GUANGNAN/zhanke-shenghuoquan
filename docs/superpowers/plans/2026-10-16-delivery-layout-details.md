# 配送布局资料的第二轮落地

**Goal:** 让商家详情更容易核对地址、进度和凭证，让骑手明确当前应前往的位置与联系对象。

**Architecture:** 基于0da041f的现有页面和数据，调整展示与交互。复用配送凭证私有解析接口与原订单动作，不增加业务状态、支付、平台回调或后端字段。

**Tech Stack:** Taro/React/TypeScript/SCSS；现有隔离行为测试与真实组件布局预览。
