# 首页入口互换与评论动效实施计划

**目标：** 首页为发现 / 二手 / 工具，私信移至底栏原二手位；完善真实二手列表、评论收展、点赞/收藏反馈。

**授权：** 用户明确要求开始修改并确认首页顺序；沿用自主实施、最后审查的约定。当前隔离工作区基线 `7c30e9b`，不覆盖原项目，不发布或上传本轮更新。

**参考：** `帖子软件排版与逻辑` 最新提交 `afb6eb3`，重点第十一轮静态手势与动效、第八轮反向/中断、第五轮长评论、新版研究导航规格。静态资源时间轴不当作真机耗时；不复制动画资产。保留原蓝色主题、咨询模块、接口、审核及身份规则。

## 设计与自审

- 选择复用现有二手页面内容、原生 ChannelPager，私信继续使用现有安全会话逻辑。避免新建重复商品实现；不启用未注册的旧 chat/conversations 页面。保留旧二手路由和分享链接。
- 首页顶部依次为发现、二手、工具；底栏依次为首页、服务、发布、私信、我的（各项继续受既有开关控制）。私信用同一首页路由的明确查询入口，作为独立内容视图，不进入公开分享。
- 二手频道懒加载，访问后保持挂载与滚动；分类保持已有服务端筛选与请求版本防乱序；分类栏自己消费横滚，不认领整页返回。卡片/分类反馈只改变内部视觉，不缩小触控框。
- 评论长正文与回复列表独立收展；收展不修改草稿、回复目标、赞和审核状态。二手通知先展开目标所在线程，再执行锚点定位；自己成功发送的回复可见。快速反向取消旧退出任务。
- 点赞/收藏确认反馈只在本次真实请求确认后触发，初次读取不播放，不通过动效延迟网络请求。失败显示可重试状态；账号或内容变化后旧结果无效。
- 二手留言没有点赞接口，本轮不造新接口/虚假计数；改进已有社区帖子/评论点赞和商品收藏。
- 本产品选择局部 120–200ms 过渡、一次短促图标确认回弹；减少动效时取消位移与回弹。原生页面进退不叠加整页 CSS 动画。

## 复审修正

- 首页固定本页入口参数，避免聊天子页成为当前 router 后将后台私信页误切成发现。
- 懒挂载二手频道第一次收到返回事件也刷新；隐藏时推迟刷新，重新进入再核对。
- 二手频道保留二手分享配置和旧直达路由；旧直达页的底栏高亮归首页，仍可点击返回发现。
- 长正文首次测量不做收缩动画。评论定位等待正文实测高度提交视图，不以固定延时当作布局完成。
- 二手通知自动展开目标，等待商品描述、图片和前置评论布局就绪；手动收起优先取消尚未完成的自动定位。
- `preverify` 注册了频道和内容动效行为检查，旧静态断言同步到共享二手组件和独立频道滚动实现。
