# 同级栏目滑动与安全返回实施计划

**目标：** 移除个人封面上的“我的”；首页私信/发现/工具、我的内容与公开主页的已有栏目支持横滑，保留各自内容位置；通用操作面板可从顶部下拉关闭，页面返回保留微信原生动画与原有业务出口。

**授权与边界：** 用户已要求自主实施并最后审查。本次在 `codex/media-review-policy-20261015` 工作区完成，不提交、不上传、不改原项目，不修改媒体审核、接口、身份守卫、模块开关和表单提交规则。既有脏改保留。

**架构：** 采用微信原生 `Swiper` 承载同级频道、每个频道独立 `ScrollView`。它提供跟手切换、方向处理和原生回位，比松手后替换内容的 CSS 动画自然，也避免在全页面自建右滑返回与图集/键盘冲突。点击和滑动共用 active key；只呈现已开放栏目，关闭不允许越界。弹层仅顶部把手认领下拉，不接管正文纵滚。全页返回继续由微信导航渲染，不叠加第二层 CSS 退场。

**技术：** Taro 4.2、React 18、TypeScript、SCSS；无新依赖。微信不支持的 `Swiper.disableTouch` 和已经失效的 `disableSwipeBack` 不作为实现依据。

## 依据与设计选择

- 参考库 `4c90abf` 的 `05-滑动与导航复刻规格.md`、第七/八轮及逐帧报告：同级栏目分别保留状态、整页原生进退、浮层优先、反向操作不留下中间态。
- 文档的 200/300ms 为单机候选，本项目频道沿用约 200ms 的标准动画；不能宣称恢复出参考产品的弹簧或触摸阈值。
- 不把底栏跳转、商品分类、图集、搜索输入和发布表单一律解释成同一种横滑。底栏保持现有路由；二手分类横滚自身拥有手势。
- 个人页只移除文字，保留封面安全区与构图间隔，避免头像和名字跟着移动。

## 验证与验收

- 组件行为：点击/滑动同步、隐藏栏目、无栏目、首末不循环、快速反向、滑后不误打开、切换不重挂内容；每个栏目滚动与分页回调归属正确。
- 下拉面板：短拖、长拖、取消、多点、loading、重复关闭与快速重开，内容区滚动不关闭。
- 返回：分享单页兜底、多层仅退一页、连续点击、失败后重试，保留已有搜索先关筛选及编辑提交锁。
- 运行相关 profile、内容、图集、弹层、导航、功能开关检查，小程序 TypeScript 与生产构建（已通过；构建仅有既有 CSS 顺序/体积警告）。
- 本地预览使用真实源码/样式和明确标识的无图结构探针，不生成图片或虚构生产数据。浏览器组件行为不代替 Android/iOS 微信真机手感验收。

自审：当前方案只补现有页面交互；没有复制第三方资产，没有后台变更，没有把研究异常当正常动画；原生页面返回与频道横滑各自负责一层。
