## 实施决定

采用“公共排版规范 + 各页面局部适配”，不统一套用卡片布局，不逐像素复刻第三方。新增纯 Sass 模块，无全局 page 选择器，页面主动引用，避免影响排除的咨询页。保留 design-tokens.scss 全部色值。

1. 页面标题 36rpx/52rpx、正文 30rpx/44rpx、评论 28rpx/42rpx、作者 26rpx/36rpx、辅助信息 24rpx/36rpx；这是项目 750 设计稿的决策，不宣称 dp 与 rpx 相等。允许现有封面大昵称、金额等语义例外。
2. 长正文/地址/说明保留换行，超长连续字符可换行，不整页 overflow:hidden 掩盖问题。作者/商品摘要保留原有行数限制；金额、时间不被长名称挤出容器。
3. 独立点击目标至少 44PX，图标视觉尺寸与触控容器分离。单行输入不强行套正文行高；按钮可容纳换行，不让固定高度裁字。状态标题、错误文字、表单说明采用一致层级。
4. 图集继续使用真实接口媒体与现有窗口自适应；不新增 AI 图/占位照片/图片评论。保留已有发布和媒体审核流程。
5. 底部操作区保留安全区和现有滚动结构；消息、订单、角色工作台不能照搬内容流。表单/账户页改长标签、窄屏与文字密度；不改业务保存或身份切换。
6. 个人页按钮右对齐且触控分离；精确匹配封面票据 400 时显示中文请求拒绝提示，其他错误仍保留实际语义。
