# 校园资讯正式范围设计

> 已撤销的设计。下文记录误解需求后的旧方案，不能作为实施或授权依据。用户要求保留原版、校园资讯独立成模块、后台可选择模式；并明确由用户自行上传和提交审核。固定范围部署已回退，后续以 `2026-10-13-independent-campus-module-design.md` 为准。

原方案错误地把用户要求理解为永久缩小服务范围。以下保留历史记录，便于解释回退原因。

## 产品与内容

首页改为校园指南目录，分「图书馆」「校区出行」，详情在小程序内完整阅读。首批五篇：开馆与自习时间、借阅账号与借还书、预约图书、电子资源、两个校区地址。仅基于湛江科技学院官网核验的事实编写原创步骤摘要，不复制学校图片、标识或文章。显示来源名称、原文链接、核验日期与“非学校官方应用”。链接可复制，不内嵌未配置域名的网页，不接管图书馆账号或预约。

内容独立于社区、商品和导航入口。使用随服务器版本发布的结构化 JSON，由独立只读 API 返回；缺失、出错、空列表均有真实反馈，无虚构统计或图片。此版不新增 CMS 和用户发布能力。内容更正走现有私密反馈；运营修改需审阅资料并发布内容版本。

## 固定发行范围

服务器启动时强制启用 campus_info 范围，20 个既有可选业务均不可开启。返回的策略是保存值与发行范围的交集；后台显示当前范围，禁用不支持的开关，API 拒绝尝试开启。该约束无环境变量、无管理 API 可解除；任何恢复业务都需代码发布及如实重新审核。

小程序自身也固定交集，即使旧 API 或缓存返回全开也不恢复业务。旧业务详情路由由既有门控拦截，首页不会请求 UGC、商品或聊天数据。保留账号、资料、注销、隐私、反馈，以及已有订单和资金的必要处理与权限；不删除历史数据，不变更用户角色。现有其他版本客户端也受服务端范围约束。

## 视觉与交互

使用现有胶囊安全区组件；白色连续画布，深灰标题、低饱和棕色小面积标记。8pt 间距，标题 20/24px、正文 16px、说明 12/14px，正文 1.7 行高。目录按同结构列表排版，不制造媒体空框。详情分段、步骤、要点；来源与免责声明在正文后。保留首页/我的底部导航、安全区、触控反馈。加载、重试、无内容和无效链接状态可恢复。

## 验收与发布

前后端测试验证固定范围、越权开关拒绝、直接接口受限、现有履约接口不误拦；内容测试验证 ID、正文、官方来源与未知 ID。分享只允许已加载的指南 ID，沿用后台标题后缀。更新关于、协议和隐私的当前服务范围，并说明历史数据处理。

采用现有安全后端测试脚本、契约检查、TypeScript/构建、微信开发工具验证。独立 release 原子部署，保存旧版本和数据库备份；不触及原工作区或既有 project.config 脏改动。上传备注只写“优化体验”，审核表单如实填本版资讯范围。上传、提交、通过、发布分别记录，不保证审核结果。

## 自审

- 未把历史测试商品或论坛帖子包装为资讯。
- 没有审核账号特例、远程复开机制、虚假数据或学校官方身份。
- 未删数据或影响旧订单处理；页面入口减少与 API 限制一致。
- 与“仅隐藏入口”方案相比，固定范围能避免缓存和直接访问越界；完整资讯 CMS 超出本轮必要范围。
- 来源 2026-10-13 核验；借阅与预约指引发布于 2022 年，正文注明以馆方最新安排为准。
