# 湛科生活圈服务型后台本地原型设计

## 目标

在不替换现有管理后台的前提下，于现有 React/Vite 项目中新增一个独立本地预览入口，把当前真实业务能力重组为“知道下一步做什么”的服务型运营工作台。

原型优先覆盖现有功能，不复制目标 SaaS 的多站点、推广员、通用表单、次卡、积分、签到和广告体系。目标后台只作为服务层级、通知模板和视觉语言参考。

## 范围

### 保留并升级

- 经营总览
- 配送与结算
- 消息通知
- 素材中心
- 审核中心
- 社区内容
- 二手商品
- 举报处理
- 商家骑手认证
- 意见反馈
- 用户与权限
- 服务入口
- 分享设置
- 功能开关
- 旧版外卖入口

### 重点补齐

- Webhook 渠道的本地新增、编辑、启停和测试。
- 消息模板的本地创建、编辑、变量预览、启停和测试发送。
- 通知发送记录的筛选、查看与失败重试。

### 明确不做

- 多站点与站点类型
- 推广员与推广等级
- 通用表单设计器
- 次卡、优惠券、积分、签到
- 激励广告与免单广告
- 小程序/服务号第三方授权

## 页面架构

新增 `apps/admin/preview.html` 和 `apps/admin/src/preview/`。现有 `index.html`、`main.tsx`、`App.tsx` 与生产后台保持独立。

预览入口采用单页工作台：

- 左侧白色导航，按“工作台 / 业务运营 / 内容与用户 / 平台设置”分组。
- 顶部栏显示当前页面、搜索、通知与预览标识。
- 主内容区采用淡蓝白色底色，组件使用 Ant Design 组件体系。
- 所有页面使用统一组件：状态标签、数据卡、表格、表单、抽屉、对话框与提示。

## 视觉方向

基调为“克制的服务运营台”：

- 主色：淡蓝 `#4a90d9`
- 背景：浅灰白 `#f5f7fa`
- 正文：深灰 `#303133`
- 标题与正文统一使用系统无衬线字体。
- 卡片使用细边框，不使用厚重阴影和装饰性动画。

## 业务交互

### 经营总览

显示真实业务语义的本地模拟指标：今日订单、配送收入、待处理审核、通知异常、骑手在岗。首屏提供“今日待办”与快捷入口，图表用简单 SVG/CSS 实现。

### 通知工作台

包含四个视图：

1. 运行概览：通道健康、发送量、异常数。
2. 消息模板：模板列表、类型、变量、启停、预览、创建与编辑。
3. Webhook：渠道列表、类型、备注、脱敏地址、启停、创建与编辑。
4. 发送记录：状态筛选、查看详情、失败重试。

模板编辑支持变量插入、实时预览和本地测试发送。Webhook 地址只显示脱敏值。

### 配送与结算

支持订单筛选、状态标签、金额汇总、选择订单、查看详情和推进状态。所有操作只写本地状态。

### 内容与审核

审核中心、社区、二手商品、举报、认证和反馈共享统一状态操作。审核动作必须有原因，状态变更即时反馈并持久化。

### 平台设置

服务入口可新增/停用入口；分享设置与功能开关提供可保存表单；用户与权限支持状态修改；旧版外卖只作为受功能开关控制的历史入口。

## 本地数据与错误处理

- 数据使用 Zustand store 管理，并持久化到 `localStorage`。
- 每个操作返回可见成功或失败反馈。
- 空列表、筛选无结果、加载和错误均有独立状态，不显示死链。
- Webhook 地址在列表和提示中脱敏。
- 预览入口不调用真实发送、支付、删除或权限接口。

## 验收

- `npm run build:admin` 通过。
- `npm run typecheck` 通过。
- 新增 `npm run check:admin-preview` 通过。
- 通过本地浏览器验证以下闭环：
  - 切换全部导航且页面有内容。
  - 新增/编辑/启停模板。
  - 新增/启停/测试 Webhook。
  - 失败记录可重试。
  - 订单详情和状态推进可操作。
  - 审核通过/拒绝需要原因。
  - 设置保存后有反馈。
  - 刷新页面后修改仍保留。
