# “账户与支持”图标细节优化设计

## 目标

在不改变“设置、用户协议与隐私政策、意见反馈、关于湛科生活圈”四个入口的文案、顺序、路由和点击区域的前提下，修正图标线条不统一、齿轮偏小且视觉重心不稳的问题。

## 现状判断

- 四枚图标虽然都使用蓝色描边，但 SVG 的画布占比、端点和连接方式不完全一致。
- “设置”齿轮使用 48 单位画布和较厚描边，外轮廓复杂、中心留白偏大，缩小到列表尺寸后容易像花形符号。
- 当前 58rpx 图标底座与 34rpx 图标组合略显拘谨，和两行文案的视觉重量不够匹配。
- 图标只负责识别入口，不能改动真实业务路由或引入新的功能含义。

## 最终方案

- 沿用项目现有 48×48 动作图标画布，统一使用 3.4 描边、圆角端点和圆角连接。
- 校正“设置”齿轮外轮廓，使外齿、中心孔和画布都以 `(24, 24)` 为视觉中心，缩小后仍保持齿轮识别度和中心平衡。
- 同步规范文档、反馈、关于三枚图标的描边属性，避免只修一枚后整组仍不协调。
- 保留现有 58rpx 浅蓝底座、34rpx 图标、列表高度、文案层级和右侧箭头，避免局部修复造成页面跳动。
- 不新增图片素材之外的依赖，不改接口、数据、路由、页面结构和其他页面图标。

## 验证

- 静态契约确认四枚 SVG 使用同一 48×48 网格、描边和圆角规则，并保持纯矢量实现。
- 资料中心专项检查确认四个真实入口和图标映射仍然存在。
- 运行小程序 TypeScript 检查、完整构建和 `git diff --check`。
- 最终视觉由用户在微信开发者工具或真机审查；本轮不上传微信版本。
