# 加载、刷新与登录反馈

用户授权优化图标、首页下拉刷新、加载失败、登录动效并检查相关问题。基线为正常版 `28bd774`，独立分支 `codex/loading-feedback-polish-20261017`；演示分支与原项目不修改。保留蓝色、现有排版、资讯/咨询内容、API、身份和功能开关；不新增业务、不部署。

审查发现：首页只有分页，无下拉刷新；初次加载为居中圆圈，不贴合双列内容；状态图形由圆环变体拼成，失败/权限/无内容含义不明确；减少动态效果仍持续旋转；私信与工具的错误/空态只有文字。二手已有刷新函数且保留旧数据，但未接原生下拉；首页 reset 失败会删除已加载内容。

选择复用既有组件并增量修复数据呈现。纯 CSS 调整不能解决刷新生命周期；全页重做会扩大范围。使用原生 ScrollView 下拉区域，原生手势不与横向 Swiper/边缘返回竞争。轻量圆弧进度、实际成功后勾形、失败静态提示；刷新并发只运行一次，切页/换账号后旧结果不回写。错误不冒充成功，刷新失败保留旧内容。首次首页双列骨架、私信列表骨架；仅透明度缓变，减少动态效果时静止。

状态图标统一 24 单位画布、1.8 笔画、圆角端点，以内容托盘、断网、文档警示、锁、用户和勾形分别表达状态。沿用本地 SVG 与品牌蓝；无装饰图片、第三方图标或新依赖。图标一次 180ms 轻显现，只有请求期间循环动画。登录用用户符号与环形等待，真实认证完成立即显示页面，不添加固定延迟或假进度。

共享状态组件保留原 props，可选登录场景；长中文错误自动换行，重试点击区至少 44px。刷新已成功状态短暂显示 450ms，失败 800ms 后释放下拉，不改变请求耗时；卸载/禁用清理计时器。功能守卫读取失败提供明确重试与返回，不改变关闭规则。

验证：组件行为覆盖双触发、成功/失败/取消、后台/卸载、账号或分类切换；首页刷新失败保留旧卡片且分页从正确页继续，图片失败后刷新允许重载；已有横滑、二手、登录隔离、功能守卫、触控和静态路由检查。TypeScript、正常包构建、原生开发者工具/隔离截图检查。系统减少动效和真机帧率仍需设备验证，不把模拟器等同真机。

追加范围：分享依次使用真实内容图片（开关开启时）、合法后台封面、内置 5:4 品牌 PNG。后台留空使用默认图，可恢复默认；不存在或未审核内容仍不可分享，CAS 和接口不变，不生成业务假图。

工具仍来自 /navigation/categories。后台补齐用途、简短标记与目标格式校验；前端采用白底分组、固定标记、名称/用途/右箭头，跳转防重入且取消不报故障。线上只读确认健康正常、导航仅有空外卖系统分类、普通工具为零。接口已具备，具体接入仍需真实 AppID、Path 与真机验证，不添加编造入口。
