# 发布入口细节优化设计

## 目标

在不改变双卡方向、真实路由和发布功能的前提下，收紧发布入口的视觉比例，让页面更轻、更整齐，并改善点击质感。

## 调整范围

- 标题区减少上下留白，标题与说明保持清晰但不过度抢占屏幕。
- 两张入口卡适度降低高度并统一内容基线，避免视觉松散。
- 图标容器、箭头容器采用更紧凑的尺寸和内外圆角层级。
- 帖子卡保留品牌蓝主层级；二手卡移除多余阴影，以边框和白底承担次层级。
- 说明文字设置一致的最小高度，保证底部分类标签对齐。
- 按压缩放改得更轻，避免卡片点击时明显跳动。

## 不变项

- 不修改 `entries` 内容、路由、点击事件与无障碍标签。
- 不新增图片、依赖、虚假内容、业务接口或页面。
- 不上传微信版本。

## 验收

- 发布与二手路由契约继续通过。
- 页面保持两列网格，卡片标题、说明和底部标签对齐。
- 类型检查、全量验证和微信小程序构建通过。
