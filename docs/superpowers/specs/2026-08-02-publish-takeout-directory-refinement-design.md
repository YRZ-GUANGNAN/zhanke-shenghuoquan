# 发布入口与学生外卖目录定向优化设计

## 目标

在不改变现有业务边界的前提下，优化学生端发布入口和外卖目录的信息层级。视觉参考成熟即时配送应用的紧凑状态导航、提示条、清晰列表卡和明确主操作，但不复制品牌、虚构功能或不存在的数据。

## 范围

### 发布入口

- 保留页面标题、返回按钮、发帖子和发布二手两条真实路由。
- 移除蓝色渐变大横幅、装饰圆圈和与两个入口重复的说明。
- 使用紧凑的白底导语区，以及两块用途明确的入口卡。
- 入口卡包含顺序标识、类型、用途说明、真实内容示例和进入箭头。
- 使用单一品牌蓝与中性色；二手入口通过弱暖色状态标识区分，不使用大面积橙色渐变。

### 学生外卖目录

- 数据继续来自 `listExternalTakeoutMerchants()`，不混入普通工具或内部配送订单。
- 保留搜索入口、商家营业／休息状态、排序、重复点击锁、`navigateToMiniProgram` 和失败提示。
- 顶部采用连续白色画布：页面标题、真实商家总数与营业中数量、完整搜索框。
- 增加“全部、营业中、休息中”本地筛选，数量完全由已加载商家计算。
- 将责任说明改为横向提示条，明确商品、价格、下单和售后由商家小程序提供。
- 商家卡强化名称和描述，营业状态与主操作分离；营业中显示“进入商家”，休息中显示“暂未营业”。
- 加载、空、错误、筛选无结果四种状态使用同一组件层级；不使用虚构图片、评分、销量、距离、配送时间、优惠或起送价。

## 不在范围内

- 不修改商家工作台、骑手配送工作台和配送订单接口。
- 不修改底部导航文字或路由。
- 不新增后端字段、数据库迁移、广告、推荐算法或商家素材。
- 不上传微信体验版或正式版。

## 交互与状态

- 发布入口卡整块可点击，并有轻微按压反馈。
- 外卖筛选只处理当前真实目录数据，不额外请求或伪造搜索结果。
- 搜索仍进入 `/pages/search/index?scope=takeout`。
- 休息商家点击后显示“商家休息中”，不会尝试跳转。
- 跳转中只锁定当前入口并显示“打开中”，防止重复调用。
- 加载失败保留点击重试；筛选无结果提供清晰说明并允许切回“全部”。

## 验证

- 新增静态契约检查，锁定两条发布路由、真实外卖数据源、三种筛选、无虚构经营字段和既有跳转保护。
- 执行发布入口、外卖目录、胶囊布局、底部导航、业务边界专项检查。
- 执行 `npm run verify` 和 `npm run build:miniapp`。
- 生成与最终提交绑定、逐文件 SHA-256 一致的待上传候选包。
