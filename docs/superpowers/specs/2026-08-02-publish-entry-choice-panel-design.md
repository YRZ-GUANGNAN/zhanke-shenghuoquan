# 发布类型选择面板设计

## 背景

当前发布入口使用编号、左侧竖线和“去发布”动作文字组织两个入口，视觉上更像后台流程选择，不符合学生端轻量、直接的发布心智。

## 目标

- 保留帖子与二手两个真实发布路由，不改变任何业务行为。
- 让用户在一眼内理解“发帖子”和“卖闲置”的区别。
- 减少说明文字、编号和重复动作，降低页面的管理感。
- 继续遵循现有白底、蓝色品牌色、圆角和克制阴影体系。

## 设计方案

1. 顶部保留胶囊安全区、返回按钮和“发布”标题。
2. 标题区改为“想发布什么？”和“选择一种内容类型开始发布”，取消眉题和频道说明。
3. 主区域使用两张并列的大点击卡：
   - “发帖子”：交流气泡图标，说明“分享动态、提问或求助”，标记“校园交流”。
   - “卖闲置”：购物袋图标，说明“发布书籍、数码与生活用品”，标记“二手交易”。
4. 取消 `01/02`、左侧竖线、“去发布”和独立箭头按钮；卡片整体响应点击与按压反馈。
5. 不使用渐变、不新增图片、不生成虚假内容，也不修改发布表单页面。

## 验收标准

- 两个入口分别进入 `/pages/publish-post/index` 与 `/pages/publish-secondhand/index`。
- 页面源码不再包含旧编号、旧频道文案、竖线和“去发布”。
- 聚焦 UI 契约、发布契约、胶囊布局、类型检查、全量验证和小程序构建全部通过。
