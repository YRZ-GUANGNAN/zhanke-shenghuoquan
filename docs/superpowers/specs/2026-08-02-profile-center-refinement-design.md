# 个人中心信息层级优化设计

## 目标

在不改变真实资料、内容统计、身份审核、身份切换、页面路由和底部导航行为的前提下，将学生端“我的”页收敛为清晰、成熟、可持续扩展的个人中心。页面不再依赖大面积品牌渐变和装饰圆形，而以真实用户信息、真实内容数据与身份状态为核心。

## 现状问题

1. 高饱和蓝色头部、悬浮统计卡和装饰圆形同时争夺注意力，资料本身反而不突出。
2. 资料区只显示首字头像，没有使用已存在的真实头像字段；“编辑资料”按钮占宽较多。
3. 四项内容统计缺少“我的内容”分组语义，数字与后续身份卡片的关系不清晰。
4. 身份入口只显示角色名称和用途，没有呈现已通过、审核中、需申请或暂不可用等真实状态。
5. 设置列表的手工 CSS 图标线条不统一，分组标题和辅助说明不足。

## 视觉与交互方案

### 顶部资料区

- 保留独立微信胶囊安全行。
- 改为白色紧凑资料头，使用小面积品牌色头像底和浅色身份标签，不使用渐变与装饰圆形。
- 优先显示 `profile.avatar`；无头像时显示昵称首字。
- 昵称、当前身份、用户号和学校形成两级信息层级；学校为空时诚实显示“学校未设置”。
- 编辑入口改为紧凑描边按钮，点击资料区或按钮仍进入现有资料编辑页。

### 我的内容

- 单独形成“我的内容”卡片，标题与“查看全部”提示明确统计用途。
- 收藏、帖子、评论、宝贝继续使用现有真实统计和原 Tab 路由。
- 数字使用等宽数字与稳定最小宽度，避免加载后抖动；四列使用轻分隔线，不增加新业务。

### 身份与工作台

- 分组标题改为“身份与工作台”，说明切换后进入对应工作台。
- 保留学生、骑手、商家三个入口和原点击逻辑。
- 每个入口增加由 `IdentityAvailability` 推导的真实状态文案：当前使用、已通过、审核中、去申请、需完善或暂不可用。
- 当前身份以浅品牌底、边框和状态字突出，不再使用悬浮角标；其他身份依据审核状态展示中性色或警示色状态。

### 账户与支持

- 现有设置、协议与隐私、意见反馈、关于四条真实路由全部保留。
- 增加分组标题和简短辅助说明，图标改为统一尺寸的简洁符号容器，保持清晰点击区域。
- 不新增静态假入口，不展示虚构认证、积分或会员能力。

## 边界

- 不修改后端、接口、数据库、身份审核状态机、身份切换命令或底部发布入口。
- 不修改微信上传配置，也不上传体验版或正式版。
- 不引入假头像、假统计、假身份状态或装饰图片。

## 验收

1. 微信胶囊与资料、编辑入口无重叠。
2. 有头像和无头像两种状态均可正确显示。
3. 四项真实统计均可进入“我的内容”对应标签。
4. 三种身份的当前、可用、待审核、未申请等状态文案与现有门禁一致。
5. 四个设置入口保持可点击且路由不变。
6. 通过静态契约、TypeScript、全量校验和小程序生产构建；不新增构建警告。
