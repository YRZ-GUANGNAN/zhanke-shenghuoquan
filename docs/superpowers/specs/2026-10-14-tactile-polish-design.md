# 小程序触感与顺滑度细节优化

## 方向与授权

用户确认不加直播等额外功能，仅优化细节，让小程序轻快、有轻微回弹且顺手。采用上一轮审查的导航触控、键盘、窗口适配和退出动效方案；沿用用户已明确的自主实施、最后审查要求。保持蓝色、已有布局、API、路由、角色、审核及开关；不改后台或部署，不引入图片与业务数据。

基线 c5ceeb4；隔离分支 codex/tactile-polish-20261014。两份 project 配置保留为用户未提交改动。参考库 631262a 第六轮只提供状态边界：不能移植异常媒体尺寸、未证实折叠规则或录屏时间戳。

## 选择

采用小幅、短时的反馈：按下 100–120ms，松开 180–220ms 的轻回弹，弹层进入约 240–260ms、退出约 180ms。不采用全页弹跳/持续动画，不用延迟真实请求换取动画。相比只改颜色/尺寸，此方案同时处理点击防重、退出中再打开和输入遮挡；相比重做交互框架，继续沿用 Taro 与 CSS、无新依赖。

## 单元与边界

1. 导航：普通入口和发布入口至少 44×44 逻辑 px；视觉图标/加号不因此放大。真实导航使用同步互斥、失败提示重试、返回后解锁；各开关组合列数保留。动效仅作用于内部视觉层，不让点击区移动。
2. 输入：帖子评论、二手私信、配送沟通处理键盘避让，滚动视口与输入栏使用同一高度来源。保持草稿、回复对象、发送协议和用户自行阅读的位置；不将收到消息强制滚到底。收键盘/切后台恢复后清理旧高度，不双重补偿。
3. 弹层：AppDialog/AppActionSheet 有独立 mounted/enter/open/exit 生命周期；关闭阶段保留画面但禁止交互，退出完成卸载，快速重开取消旧退出任务。loading 保持原关闭语义；不吞业务回调，不重复确认。
4. 窗口与字号：已有页面壳在窗口改变/回到前台时刷新安全区读数，不重挂载业务页，不重读业务接口。仅现有 reference-layout 角色字号增加合理上下限与比例行高，保留咨询例外。图集已有生命周期不重写；大屏不是无限放大文字。
5. 减少动效：支持 prefers-reduced-motion，状态通过颜色/文字仍清楚；不以性能测量缺失宣称全机型 60/120Hz。

## 验证

每单元先有行为/几何测试：重复点击、失败恢复、快速开关、旧定时器、卸载、窗口变化、键盘展开/收起、320/360/375/390/430/768 宽度。运行全部 verify 与微信构建，保留分享、评论、二手、权限和咨询回归。浏览器检查实际组件/样式，不把静态样本称为小程序真机验收；iOS/Android 真机键盘、系统大字号与基础库兼容单列待测。

自审：不新增业务，不更改审核/生产开关，不复制第三方资产；无全页动画、永久锁或无退出清理的计时器。使用短时 opacity/transform，布局变化不做高成本逐帧插值。
