# 小程序触感与顺滑度细节优化

## 方向与授权

用户确认不加直播等额外功能，仅优化细节，让小程序轻快、有轻微回弹且顺手。采用上一轮审查的导航触控、键盘、窗口适配和退出动效方案；沿用用户已明确的自主实施、最后审查要求。保持蓝色、已有布局、API、路由、角色、审核及开关；不改后台或部署，不引入图片与业务数据。

基线 c5ceeb4；隔离分支 codex/tactile-polish-20261014。两份 project 配置保留为用户未提交改动。参考库最新基线 5278dd8（第七轮）只提供状态边界：不能移植异常媒体尺寸、未证实折叠规则、手势阈值、内部弹簧公式或录屏时间戳。

## 选择

采用现有动效令牌的轻反馈：按下使用约 120ms 的 opacity/scale 视觉反馈，弹层沿既有 260ms 进入令牌并增加可取消的退出阶段；不把参考录像的采样间隔、拖拽距离或面板/媒体不同步过程写成硬阈值。不采用全页弹跳、持续动画或自定义边界弹簧，不用延迟真实请求换取动画。相比只改颜色/尺寸，此方案同时处理点击防重、退出中再打开和输入遮挡；相比重做交互框架，继续沿用 Taro 与 CSS、无新依赖。

## 单元与边界

1. 导航：普通入口和发布入口至少 44×44 逻辑 px；视觉图标/加号不因此放大。真实导航使用同步互斥、失败提示重试、返回后解锁；各开关组合列数保留。动效仅作用于内部视觉层，不让点击区移动；不为导航增加参考应用式全页转场。
2. 输入：帖子评论、二手私信、配送沟通处理键盘避让，滚动视口与输入栏使用同一高度来源。保持草稿、回复对象、发送协议和用户自行阅读的位置；不将收到消息强制滚到底。收键盘/切后台恢复后清理旧高度，不双重补偿。系统返回、关闭输入层和页面返回按本项目既有路由处理，不复制参考应用“第一次返回留编辑层”的未验证通用规则。
3. 弹层：AppDialog/AppActionSheet 有独立 mounted/enter/open/exit 生命周期；关闭阶段保留画面但禁止交互，退出完成卸载，快速重开取消旧退出任务。loading 保持原关闭语义；不吞业务回调，不重复确认。
4. 窗口与字号：已有页面壳在窗口改变/回到前台时刷新安全区读数，不重挂载业务页，不重读业务接口。仅现有 reference-layout 角色字号增加合理上下限与比例行高，保留咨询例外。图集已有生命周期不重写；大屏不是无限放大文字。
5. 减少动效：支持 prefers-reduced-motion，状态通过颜色/文字仍清楚；遮罩只使用项目现有中性层级，不复制参考样本约 20% 黑色的像素拟合；不以性能测量缺失宣称全机型 60/120Hz。

## 验证

每单元先有行为/几何测试：重复点击、失败恢复、快速开关、旧定时器、卸载、窗口变化、键盘展开/收起、320/360/375/390/430/768 宽度；图集只验证既有 Swiper 翻页/首尾不越界，不新增自定义拖拽阈值。运行全部 verify 与微信构建，保留分享、评论、二手、权限和咨询回归。浏览器检查实际组件/样式，不把静态样本称为小程序真机验收；iOS/Android 真机键盘、系统大字号、手势边界和基础库兼容单列待测。

自审：不新增业务，不更改审核/生产开关，不复制第三方资产；无全页动画、永久锁或无退出清理的计时器。使用短时 opacity/transform，布局变化不做高成本逐帧插值。
