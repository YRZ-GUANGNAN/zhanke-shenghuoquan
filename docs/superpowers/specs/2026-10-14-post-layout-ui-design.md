## 范围与参考

依据本地 `C:/Users/33141/Documents/Codex/帖子软件排版与逻辑` 的排版测量、图文详情状态机和滑动导航研究。研究对象为小红书 Android 8.72.0；原设备像素、品牌色、内容、图标和未验证能力不移入本项目。

采用其通用原则：媒体有稳定容器，文字有明确层级，横向图片与纵向正文分别滚动，状态与内容区分，返回保留来源。具体尺寸按本项目 750 designWidth 独立确定。

不改任何色值、后端、接口契约、角色、身份守卫、功能开关或路由。保留首页当前帖子与商品聚合能力，并标明二者类型；独立二手市场仍使用原页面。直播、视频流、群聊、推荐算法、专辑、嵌套评论均不接入。只使用接口已有图片，无图片时展示真实文字结构。

## 设计决定

评估过三种路径：只改 CSS 无法修复附件和评论行为；整套复刻会引入现有项目没有的功能；因此采用“保留现有结构与服务，重整帖子展示并复用现有共享组件”的路径。

1. 首页发现：连续白色内容面，两列外侧 24rpx、中缝 16rpx。帖子媒体统一 4:5 展示窗、商品 1:1 展示窗；不再按编号制造随机高度。标题 28/40rpx，最多两行；作者 22/32rpx，单行截断；原图数量按真实附件显示。无图帖以正文摘要填充文字区，不绘制假封面。商品展示现有价格与商品分类，收藏用收藏图标。
2. 帖子详情：保留胶囊安全区、固定作者栏和底部操作栏。已有多图附件均可横向查看；同帖保持一个媒体高度，比例取首张有效图并受 360–820rpx 与屏高约束，`aspectFit` 避免正文截图被裁切。失败附件不阻断其他图片；全部失败时明确提示。正文左右 32rpx，标题 36/50rpx，正文 30/48rpx，评论 28/44rpx。
3. 评论和互动：保留赞、收藏、关注与评论接口。评论图标回到评论区，发送使用输入框发送或明确的“发送”按钮，避免点评论数误发送。提交期间保留输入且阻止重复请求；失败复用原幂等号。没有回复接口的评论不再显示暗示可点的“回复”。没有任何可用互动时不渲染空底栏。
4. 整体一致性：帖子相关页面与搜索、我的内容、发布页采用相同文字层级及 8rpx 基础间距，功能完整保留。校园指南/咨询模块及其共享导航、状态、标题样式保持当前版本，不纳入本次修改。
5. 状态：加载、空列表、失败可重试分别显示；已有内容分页失败时保留内容。媒体失败保持列表容器稳定；详情重试与图片请求均隔离陈旧响应。分享入口首次打开后的返回首页兜底保持原实现。
