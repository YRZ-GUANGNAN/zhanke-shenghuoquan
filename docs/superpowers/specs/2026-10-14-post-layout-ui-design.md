## 设计决定

评估过三种路径：只改 CSS 无法修复附件和评论行为；整套复刻会引入现有项目没有的功能；因此采用“保留现有结构与服务，重整帖子展示并复用现有共享组件”的路径。

1. 首页发现：连续白色内容面，两列外侧 24rpx、中缝 16rpx。帖子媒体统一 4:5 展示窗、商品 1:1 展示窗；不再按编号制造随机高度。标题 28/40rpx，最多两行；作者 22/32rpx，单行截断；原图数量按真实附件显示。无图帖以正文摘要填充文字区，不绘制假封面。商品展示现有价格与商品分类，收藏用收藏图标。
2. 帖子详情：保留胶囊安全区、固定作者栏和底部操作栏。已有多图附件均可横向查看；同帖保持一个媒体高度，比例取首张有效图，按逻辑窗口宽度与 0.75–2 比例夹取计算，再扣除标题栏、底栏、安全区并为正文留出空间（第四轮替代原 360–820rpx 固定约束）。`aspectFit` 避免正文截图被裁切。失败附件不阻断其他图片；全部失败时明确提示。正文左右 32rpx，标题 36/50rpx，正文 30/48rpx，评论 28/44rpx。
3. 评论和互动：保留赞、收藏、关注与评论接口。评论图标回到评论区，发送使用输入框发送或明确的“发送”按钮，避免点评论数误发送。提交期间保留输入且阻止重复请求；失败复用原幂等号。没有回复接口的评论不再显示暗示可点的“回复”。没有任何可用互动时不渲染空底栏。
4. 整体一致性：帖子相关页面与搜索、我的内容、发布页采用相同文字层级及 8rpx 基础间距，功能完整保留。校园指南/咨询模块及其共享导航、状态、标题样式保持当前版本，不纳入本次修改。
5. 状态：加载、空列表、失败可重试分别显示；已有内容分页失败时保留内容。媒体失败保持列表容器稳定；详情重试与图片请求均隔离陈旧响应。分享入口首次打开后的返回首页兜底保持原实现。

## 第三轮：二手浏览链路

用户已确认“将二手页面也按当前逻辑修改”。沿用本说明的颜色、媒体、文字层级与稳定状态原则，范围为二手集市、商品详情及留言、二手发布，不涉及咨询模块、私信业务实现或后端。

再次核对参考库 `measurements.md` 的 F13/F14/F17、G02/G14，以及 `K132-feed-restore.java.txt` 中数据与滚动位置分别恢复的机制。参考库没有交易研究；仅采用受控间距、固定媒体窗口、返回保留浏览上下文，不套用社区业务。

- 集市：连续白色画布，24rpx 外边距、16rpx 列间距、1:1 真实商品主图，标题 28/40rpx 固定两行；价格保留原语义色，分类/成色与卖家按接口显示。不再按编号随机高度或生成彩色纹理。分类名称、搜索域和在售查询均保留。
- 返回与分页：详情返回不清空列表或重建滚动容器；后台刷新已加载页，失败保留旧内容并可重试。分类切换作废旧请求；分页同步锁防止同帧重复触底。关闭二手时不继续请求。
- 详情：全部真实商品附件可横滑、原图预览；使用固定正方形媒体区与 `aspectFit`，失败邻图不改变当前图身份，全失败保留区域并明确提示。无图不伪造封面。价格、状态、标题、说明、卖家和留言按章节衔接。
- 留言：保留一级留言、回复、卖家标记、真实审核状态及原幂等请求。初次读取、分页和提交互斥；失败保留输入和已读内容，迟到响应不能覆盖新商品。已售状态继续禁止留言。
- 发布：已有全部上传附件可见，第一张仍为封面；保留移除封面能力、9 张限制、原字段及校验。上传/提交同步防重，提交期间锁定字段和分类，失败保持提交内容与请求身份。表单与底栏遵循安全区及 88rpx 触控基线。
- 视觉边界：所有样式限于上述二手页面；不改设计令牌值、不增加全局选择器，不影响咨询依赖。没有收藏或联系权限时不渲染空操作栏，卖家状态管理完整保留。

自审：这是一轮已支持功能的展示与交互修复；不增加排序、支付、担保、草稿、私信类型或权限。接口、路由、分享和守卫保持原契约。原工作区、线上环境和两个已有配置改动不纳入提交。
