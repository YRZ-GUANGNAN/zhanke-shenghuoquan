# 私信与二手交易界面一致性设计

## 目标

在不改变腾讯云 IM、商品、用户主页、关注、筛选和设置接口的前提下，统一私信及二手交易相关页面的视觉层级与交互反馈，使它们呈现为同一个成熟产品，而不是四套彼此独立的页面。

## 设计方向

- 使用现有设计令牌中的白色表面、冷灰背景和单一品牌蓝，不引入新字体、图片或第三方组件。
- 商品和交易状态优先于装饰。减少大面积纯色、过宽按钮和胶囊堆叠。
- 统一圆角层级：页面容器不加卡片感，信息卡使用中等圆角，标签和状态才使用小胶囊。
- 真实图片正常展示；无图片时保留诚实的分类占位，不生成虚假商品图。
- 保留微信胶囊独立安全区、iOS 键盘安全区、底部导航和现有页面路由。

## 页面设计

### 私信会话

- 顶部只保留返回、对方头像与姓名、在线会话状态及主页入口，弱化“腾讯云 IM”等工程性文字。
- 商品摘要变为紧凑的可点击交易条，突出商品标题、价格和状态。
- 安全提醒缩成会话流顶部的次级提示，不占据主要内容高度。
- 空会话提供自然的开场提示；消息气泡限制最大宽度并区分双方层级。
- 输入区改为左侧图片入口、中间输入面、右侧独立发送按钮；未输入时禁用但保持清晰轮廓。
- 键盘弹出时只移动消息流和输入区，不改变顶部信息结构。

### 二手集市

- 搜索框占据标题下方主要横向空间，分类改成轻量横向筛选。
- 安全提示压缩为单行信息条。
- 商品卡统一媒体比例，取消由随机高度造成的单商品页面失衡；一件商品时使用更稳定的双列栅格宽度。
- 商品标题、价格、分类与状态形成固定信息顺序；售罄状态只做降权，不制造高对比遮挡。
- 加载、空、失败与到底状态继续使用真实接口结果。

### 用户主页二手标签

- 移除大面积品牌蓝头图，改为白底身份摘要与轻量统计区。
- 关注为唯一主按钮，“查看在售商品”改为次级动作。
- 内容区与集市共用相同的商品卡比例和状态规则。
- 自己的主页不显示关注动作，保留分享及内容入口。

### 设置

- 保留所有真实开关、手机号授权、黑名单、更新、反馈、关于和退出能力。
- 账号状态在顶部用摘要卡展示；其余按“通知与偏好、隐私与安全、支持与关于”分组。
- 开关提供按压反馈、保存中状态和失败回滚，不改变现有 PATCH 契约。
- “develop”版本文字改为用户可理解的版本说明，但不伪造线上版本号。

## 数据与错误边界

- 所有页面继续调用现有 `c-trade.ts`、`e-im.ts` 和 `a-user.ts`。
- 不新增假商品、假用户、假会话、假统计或占位评分。
- 网络错误保留重试入口；身份失效交由现有单次会话恢复机制处理。
- 商品下架后会话仍可显示关系摘要，但不允许错误跳转到不存在的详情。

## 验收

- 四个页面通过 TypeScript、生产构建和现有完整 `npm run verify`。
- 新增静态契约检查，验证私信输入区、真实商品列表、用户主页与设置能力未被视觉修改移除。
- 在微信开发者工具分别挂载私信、二手集市、用户主页和设置页，检查胶囊避让、空态、单商品布局与键盘输入。
