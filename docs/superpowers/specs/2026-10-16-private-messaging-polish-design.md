# 私信模块体验优化设计说明

## 目标与边界

本轮只优化现有私信入口与二手交易单聊的视觉层级、交互反馈和页面状态，不新增业务能力。保留现有腾讯云 IM、会话权限校验、商品上下文、文本消息发送、路由与返回兜底；不新增图片、语音、视频、群聊、转发或后端字段，不修改咨询模块和审核策略。

## 信息架构

- 首页私信是“会话列表”链：每一行以真实商品主图/无图态、商品标题、交易角色与关系编号表达归属；加载、空态、失败重试和底部说明独立呈现。
- `/pages/secondhand-chat/index` 是“单聊”链：顶部对方身份，商品上下文，安全提示，消息列表，输入区。两条链只通过现有 `relationId` 路由连接，不把通知或商品列表混入会话列表。
- 当前接口没有最近消息、未读数、草稿、置顶或免打扰字段，界面不伪造这些状态；待后端真实返回后再映射。

## 视觉与交互决定

- 使用现有蓝色主题和 8pt/rpx 节奏；白色连续画布、弱分隔线、轻按压反馈，避免重卡片墙。
- 会话行的主层级为“商品标题 → 交易角色/关系 → 入口提示”，商品图仅作真实商品附件；无图时使用中性文字空态。
- 会话行保持至少 44px 触控区，滑动后通过 `canActivate()` 阻止误触；返回后继续使用当前账号对应的数据，不保留旧账号异步结果。
- 单聊增加日期分组语义（使用消息自身时间计算“今天/昨天/具体日期”），不改变消息 ID 或分页合并；输入区保持现有单行文本能力，发送中禁用，失败保留草稿并提示重试。
- 返回优先收起键盘/输入层，再执行现有 `navigateBack` 及 fallback；不增加整页转场动画。局部动画只用于按压、输入区和新消息出现，尊重 `prefers-reduced-motion`。

## 数据与安全

只读取已有 `IMConversationContext`、`Product` 和腾讯消息字段。商品标题、图片、卖家名称、价格和关系编号均来自真实接口；不公开真实私信内容、头像原图或账号标识，不将研究中的第三方字段写成产品能力。

## 自审结论

改动集中在 `home` 会话列表和 `secondhand-chat` 单聊页，风险低且可回退；业务契约与生产身份守卫不变。需要真机进一步确认的是键盘高度、不同系统的返回事件和腾讯云实时消息到达时机。
